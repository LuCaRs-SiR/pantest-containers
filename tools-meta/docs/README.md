# Dokumentacja projektu

Ten katalog porzadkuje dokumenty operacyjne i projektowe, aby katalog glowny repozytorium pozostawal czytelny.

## Struktura

- `project/ROADMAP.md` - plan rozwoju i kamienie milowe.
- `operations/LOGS.md` - konwencje logowania i oczekiwane sciezki logow.
- `maintenance/PR_DESCRIPTION_SYNC_WITH_WORKSPACE.md` - opis zmian porzadkowych repo.
- `maintenance/SAFE_STORAGE_SLIMMING_PLAN.md` - plan bezpiecznego odchudzania miejsca na dysku.

## Zasady

- Dokumenty stale i strategiczne trafiaja do `project/`.
- Dokumenty operacyjne trafiaja do `operations/`.
- Dokumenty jednorazowe lub serwisowe trafiaja do `maintenance/`.
