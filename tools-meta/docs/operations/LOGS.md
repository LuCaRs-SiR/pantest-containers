# Logs Directory

This project stores tool logs centrally under the `logs/` directory. The panel backend mounts this directory to collect outputs and keep history.

## Expected log paths

- `logs/nmap.log`
- `logs/recon.log`
- `logs/inspector.log`
- `logs/ai.log`

## Setup

Create the logs directory in the repo root:

```bash
mkdir -p logs
```
