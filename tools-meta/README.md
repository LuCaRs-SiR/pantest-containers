# Tools Meta

Katalog `tools-meta` zawiera elementy pomocnicze i operacyjne, ktore nie sa bezposrednio kodem uslug runtime.

## Zawartosc

- `assets/` - grafiki uzywane w README i dokumentacji.
- `docs/` - dokumentacja projektowa, operacyjna i utrzymaniowa.

## Cel

Utrzymanie czytelnego katalogu glownego repozytorium: w root pozostaja glownie punkty wejscia projektu (`README.md`, `LICENSE`, `docker-compose.yml`) oraz katalogi uslug.
